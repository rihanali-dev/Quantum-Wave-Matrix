# 🪔 Quantum Wave Matrix | Algorithmic Kolam Visualizer

An interactive, festive web-based simulation blending traditional Indian art (Kolam) with mathematical coordinate matrices and wave interference, built specially for Diwali.

---

## ✨ Features
* **Interactive Wave Field:** Real-time particle interference grid responding smoothly to mouse movement.
* **Mathematical Modeling:** Showcases coordinate grid dynamics and loop calculations.
* **Festive Aesthetic:** Designed with a rich Diwali brown gradient (`#5B2C1F`) and warm golden-amber lighting glows.
* **Historical Recognition:** Honoring foundational research in array grammars and computational patterns.

---

## 📐 Historical Context & Formula
> *"A kolam is an algorithm. Rule: the line bounces at the edge and never breaks."*[cite: 1]
